Fixes Shipped

  • Scoped file reveal: src/utils/url.ts now invokes a Tauri command that validates external reveal paths through the vault boundary before calling the native opener.
  • Narrower Tauri capabilities: src-tauri/capabilities/default.json now grants restart plus scoped URL opening instead of broad process/opener defaults.
  • Telemetry redaction: src/lib/sensitiveTextRedaction.ts now redacts macOS, Unix, and Windows absolute paths with spaces, including C:/Users/... and C:\Users\... forms.
  • UTF-8 safe provider errors: Rust AI provider error truncation no longer slices inside multibyte characters.
  • Premium press feedback: shadcn button variants moved to src/components/ui/buttonVariants.ts, reducing Fast Refresh noise and adding deliberate pressed feedback.
  • Listbox accessibility: note list, search panel, and autocomplete rows keep active-descendant and keyboard activation semantics closer to expected desktop behavior.
  • Timer cleanup: dialog, palette, search, and emoji picker timeouts use browser timer IDs with matching cleanup.
  • Localization: changed AI-key storage copy lives in en.json and has translated entries in all 17 non-English catalogs. Lara translation could not run because credentials were absent, so translations were manually provided and validated for key shape.
  • Docs: docs/ABSTRACTIONS.md and docs/ARCHITECTURE.md document the scoped file reveal/external file command boundary.
