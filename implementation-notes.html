Resolved High Findings

  • Clone destination authority: clone_git_repo now accepts only a new direct child under ~/Vaults, and low-level clone cleanup removes only destinations created for the current failed attempt.
  • AI agent vault roots: stream_ai_agent validates vault_path and every vault_paths entry through the registered vault boundary before subprocess/MCP use.
  • Rename/wikilink boundaries: rename detection and wikilink rewrite commands re-enter the vault boundary, reject absolute/traversing paths, avoid symlink following, and abort before moving files when frontmatter title updates fail.
  • Release history XSS: the generated release page ignores any GitHub-rendered body_html, escapes markdown from body, and allows only safe HTTP(S) links. Workflow header cleanup was intentionally removed from the pushed commit because the available GitHub OAuth token lacks workflow scope; the renderer-side trust boundary is the security fix.
  • Modal and search accessibility: Search, Quick Open, and Command Palette gained focus trapping, accessible names, combobox/listbox active-descendant semantics, localized labels, and labeled result listboxes; Search now uses the shadcn Input.
  • Keyboard resizing: pane resize handles now expose separator semantics, labels, focus styles, and Arrow-key resizing.
  • Root crash fallback: React root rendering is wrapped in a visible, localized RootErrorBoundary, while uncaught startup errors still get a localized emergency fallback path. The pre-React emergency overlay uses direct DOM construction by necessity because component rendering has already failed.
  • External opener safety: browser-mode URL fallback uses noopener,noreferrer.
  • Localization: create-note, create-type, commit dialog, search, resize, and touched App toast copy now route through locale catalogs.
  • Plural copy: touched count strings use singular/plural translation keys instead of English suffix placeholders.
  • Reusable search list contract: NoteSearchList now requires an accessible listbox label at every call site. Existing wikilink, raw-editor, relationship, and quick-open result lists are labeled through locale catalog keys.

Intentional Deviations

  • No new dependencies were added. The fixes reused existing boundary utilities, shadcn components, test harnesses, and local renderers.
  • Full shadcn/Radix migration of every custom overlay and context menu is deferred as medium follow-up; this pass fixed modal focus/semantics for the high-risk palettes changed by the review.
  • PostHog: no new event was added because this pass hardens existing flows rather than adding a new discoverable user action.
  • ADR: none. The work strengthens existing vault-boundary, localization, accessibility, and release-rendering contracts without introducing a new architectural dependency or storage strategy.
